AYESHA FAHEEM — HTML5 + CSS3 PORTFOLIO WEBSITE
================================================

FILES
- index.html       Home page
- about.html       About page
- services.html    SEO, social media advertising, social media management
- portfolio.html   Sample practice projects (clearly labelled)
- blog.html        Links to your existing blog
- contact.html     Contact enquiry form (mailto-based placeholder)
- css/style.css    Responsive styling
- robots.txt       Basic crawler instructions
- sitemap.xml      Starter sitemap

HOW TO VIEW
1. Extract this ZIP file.
2. Open index.html in a web browser.
3. Use the navigation to visit the other pages.

IMPORTANT BEFORE PUBLISHING
1. Replace https://example.com/ in canonical links, structured data, robots.txt and sitemap.xml with your final portfolio website URL.
2. In contact.html, replace YOUR-EMAIL@example.com with the email address where you want to receive enquiries.
3. The contact form uses mailto. It opens the visitor's default email app and is not a server-side form. For reliable submissions, connect a form service or add a backend.
4. Add your real profile photo and update the CSS if you want to use it instead of the designed AF monogram.
5. Add your valid Instagram/WhatsApp links only if you want them displayed.
6. The sample portfolio items are demonstrations, not real client results. Replace them with your own work as you complete projects.
7. Blog article titles are not fabricated. The blog page links to your existing blog at https://ashoofaheem.free.nf/.
8. Test all pages, links, form fields, mobile layouts and SEO metadata after uploading.

DESIGN
- Built with HTML5 and CSS3 only; no framework required.
- Responsive navigation uses a CSS checkbox.
- FAQ accordion uses native HTML details/summary.
- Uses semantic structure, descriptive titles, meta descriptions, responsive CSS and reduced-motion support.
- Example domain is a placeholder; update it before publishing.
